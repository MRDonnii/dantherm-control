# Dantherm Control 1.13.0-beta.8

Rettelser til mobilvisningen, når der er en opdatering tilgængelig.

## Topbjælken

- På telefoner og smalle tablets viser knappen **Opdatering** eller **Installerer**. Det fulde versionsnummer og installationsstatus findes på siden **Opdateringer**; skærmlæsere får den fulde tekst.
- Vejrvisningen viger i topbjælken, mens opdateringen vises, og kommer tilbage, når der ikke er en opdatering. Sidens almindelige temperaturvisning er fortsat tilgængelig.
- Knapgruppen får den plads, den kræver. Sidetitlen afkortes, så titel og knapper ikke overlapper på smalle skærme. Søgning, HA-status og konto bliver inden for skærmen.
- Desktop beholder den fulde opdateringstekst, versionsnummer og vejrvisning.

## Bundbjælken

- Den røde badge på **Mere** placeres i forhold til ikonets egen ramme. Den ligger dermed ved ikonet frem for ude ved højre skærmkant.
- Ikoner og etiketter flugter på tværs af de fem faner. Telefonens sikre områder ved skærmkanterne bevares.

## Opdatering og kompatibilitet

Vælg beta-kanalen på **Opdateringer** og hent **1.13.0-beta.8**. Denne version indeholder også beta.7's sammenligning før og efter opdateringer.

Ændringen vedrører kun visningen. Ingen indstillinger, HA-entity-ID'er eller reguleringsfunktioner ændres. Eftervarmens eksisterende indirekte HAC1-styring er bevaret; direkte procentvis 0–10 V afventer hardwarekortet. HA-integrationen kræver ingen opdatering.

## Validering

237 frontendtests, TypeScript og produktionsbuild består. Browserkontrol af produktionsbuildet dækker Command/Aurora, opdatering klar, installation i gang og ingen opdatering ved 320, 360, 375, 390, 430, 768 og 1440 px. Mobilkontrollen måler knappernes placering og vandret overløb med sidens overløbsbegrænsning slået fra. Telefonens sikre områder er desuden kontrolleret med emulerede insets i højformat og landskab. Badgen ligger ved Mere-ikonet, og søgefokus samt den åbne Mere-menu bevares under almindelig datapolling. Desktopkontrollernes placering ved 1440 px er sammenlignet med beta.7 og er uændret. Ingen fysisk regulering afprøvet.
